Belajar bareng lewat Discord

Belajar 1 lawan 1 denganku di server Discord. Kita urai materi yang belum kamu pahami pelan-pelan, sambil berbagi layar. Ada program bertahap dan ada sesi satuan. Setiap Sabtu, 19.00 sampai 20.00 WIB, ada juga kelas bareng gratis untuk siapa pun.

  1. Pilih program dan bayar

    Tambahkan ke keranjang, bayar pakai QRIS, lalu konfirmasi lewat WhatsApp.

  2. Masuk server Discord

    Aku kirim undangan server dan membuat channel pribadi untukmu.

  3. Atur jadwal

    Pilih jam yang cocok. Kirim dulu materi atau tugas yang mau dibahas.

  4. Sesi 60 menit

    Kita ngobrol lewat voice channel dan berbagi layar. Catatan sesi tetap ada di channel-mu.
