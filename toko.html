Cara pesan

Dari keranjang sampai file di tangan

  1. Langkah 1

    Pilih produk atau program

    Tekan Tambah di produk atau Daftar di program bimbel, lalu buka keranjang di pojok kanan atas.

  2. Langkah 2

    Isi nama dan WhatsApp

    Isi juga emailmu kalau mau file dikirim ke kotak masuk. Boleh dikosongkan, nanti file kukirim lewat WhatsApp.

  3. Langkah 3

    Bayar pakai QRIS

    Scan QRIS dan ketik nominal persis, termasuk kode unik 1 sampai 199 rupiah di ujungnya.

  4. Langkah 4

    Kirim bukti lewat WhatsApp

    Pesan konfirmasi sudah tersusun otomatis. Tinggal lampirkan tangkapan layar bukti bayar.
